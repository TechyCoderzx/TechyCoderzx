## 🚀 Featured Projects

### 🌿 [WildLens](https://github.com/TechyCoderzX/wildlens)

An AI-assisted nature field guide that analyzes photos of organisms and provides identification hypotheses, visible evidence, lookalikes, and suggestions for what to observe next. Includes voice interaction and spoken summaries.

**Tech:** React, Vite, JavaScript, Python, FastAPI, Gemma 4, Gemini API, ElevenLabs

[Live website](https://wildlens-frontend.onrender.com)

### 🔎 [Riptide — RAG Email Search](https://github.com/TechyCoderzX/RAG)

A voice-and-text search application for the Enron email archive. Uses semantic retrieval and zero-trust retrieval checks to help identify and block prompt-injection attempts before answer generation.

**Tech:** React, Vite, Python, FastAPI, embeddings, FAISS

### 🌫️ [Air Quality Trend Predictor](https://github.com/TechyCoderzX/AirQualityIndex-)

A machine learning project that predicts next-hour PM2.5 concentrations using historical air-quality and weather readings from the Beijing Multi-Site Air Quality dataset. Uses chronological evaluation and Linear Regression as its only predictive model.

**Tech:** Python, Pandas, Scikit-learn, Matplotlib, Linear Regression
